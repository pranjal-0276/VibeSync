📌 Overview

VibeSync is an AI-powered platform that helps users create personalized music experiences based on moods, vibes, and collaborative interactions. Whether you're studying, relaxing, traveling, or hanging out with friends, VibeSync generates playlists and recommendations that match the collective energy of the moment.

The project combines modern frontend technologies with AI-driven recommendations to deliver a seamless and engaging music experience.

✨ Features
🎧 AI-powered playlist generation
💬 Real-time collaborative vibe syncing
🧠 Mood-based music recommendations

⚡ Fast and responsive UI
